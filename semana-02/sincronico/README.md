# Semana 2 · Decisiones, colecciones y funciones

Durante esta sesión acompañaremos una jornada del Estudio Horizonte. Comenzaremos
por una regla aplicada a una persona y, paso a paso, construiremos una operación
capaz de revisar varios registros, organizar resultados y reutilizar el proceso.

El cuaderno contiene once problemas para resolver durante la clase. Cada
enunciado aparece justo antes de su celda editable. Los primeros conservan parte
de la estructura; los últimos dejan más decisiones en tus manos.

Desde la raíz del repositorio:

```bash
uv run marimo edit semana-02/sincronico/lesson.py
```

## Cómo trabajar con los problemas

1. Lee primero qué necesita el equipo del estudio.
2. Identifica la información disponible y el resultado esperado.
3. Escribe y ejecuta una primera solución.
4. Compara tu estrategia con las que se revisen durante la clase.
5. Corrige tu celda y conserva la versión que puedas explicar.

El estudio y sus registros son ficticios. Su función es ofrecer un contexto común
para practicar lógica y programación, no representar decisiones clínicas reales.
