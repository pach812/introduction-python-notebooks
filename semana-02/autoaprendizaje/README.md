# Semana 2 · Ruta de autoestudio

Esta ruta amplía las ideas que utilizamos durante la sesión. Puedes seguirla
completa, detenerte después de cada tema o regresar directamente a una unidad
cuando quieras repasar una estructura o una forma de resolver problemas.

Desde la raíz del repositorio público:

```bash
uv sync
uv run marimo edit semana-02/autoaprendizaje/01_reglas_y_control.py
```

## Recorrido recomendado

1. `01_reglas_y_control.py`
2. `02_listas.py`
3. `03_tuplas.py`
4. `04_diccionarios.py`
5. `05_conjuntos.py`
6. `06_comparar_estructuras.py`
7. `07_recorridos.py`
8. `08_funciones.py`
9. `09_comprensiones.py`
10. `10_pruebas_y_errores.py`

Las primeras seis unidades se concentran en decisiones y estructuras de datos.
Las cuatro últimas muestran cómo recorrer, transformar, organizar y comprobar el
código que construyes con ellas.

Cada unidad parte de una pregunta, desarrolla el concepto con ejemplos y termina
con ejercicios. Escribe tus respuestas, incluso cuando no se evalúen: ese intento
te permitirá comparar lo que esperabas con lo que Python realmente hizo. Si una
actividad no sale a la primera, usa las pistas de manera gradual y vuelve a
ejecutar tu solución.
